# 메뉴 이미지

`메뉴판(최종)`의 일러스트 13개와 추가 제공된 소주·맥주 사진 2개를
WebP(quality 88)로 인코딩한 배포 자산입니다.
원본 PNG는 수정하지 않았으며 원본 해상도·비율·알파 채널을 유지합니다.
총 15개 용량은 5,743,745 bytes → 682,570 bytes(약 88% 감소)입니다.
소주·맥주 사진은 제공된 흰 배경을 그대로 유지합니다.

- `manifest.json`: 원본 파일명, 정확한 메뉴 ID, 크기, SHA-256, 현재 배포 파일 경로.
- `<menuId>/<sha256 앞 16자리>.webp`: 불변 파일명. 이미지 교체 시 새 파일을 추가합니다.
- 이전 파일을 지우면 Terraform에서 원격 객체도 삭제하므로 롤백·캐시 유효 기간 동안 보관합니다.
- 첨부 이미지가 없는 세트 메뉴·기본 하이볼·콜라·사이다에는 다른 그림을 임의로 연결하지 않습니다.

버킷 생성·배포·DB 연결 절차는 [메뉴 이미지 운영 가이드](../../docs/qr-order/menu-images.md)를 따릅니다.
