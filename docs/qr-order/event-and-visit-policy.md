# 확정 운영 정책: 입장·예약·엽전 주문

2026-09-16 확정 요구사항을 구현한 정책이다. 기존 문서와 다른 메뉴 옵션·주방 라우팅·방문 활성화 규칙은 이 문서를 따른다. 구현/API/검증 상세는 [PR 문서](../pr/event-management.md)에 기록했다.

## 테이블 방문

빈 테이블은 입장 전 합석할 수 있다. 사전 합석은 입장 시간이 없는 준비 상태이며, 관리자 입장 또는 최초 고객 주문 시 그룹 전체가 활성화된다. 첫 활성화 시각을 유지하고 합석 테이블끼리 현재 방문의 주문 내역을 공유한다.

테이블마다 `입장 35분 경과`를 표시한다. 예약 방문에는 `퇴장까지 75분`, 예정 시각 경과 후에는 `퇴장 5분 초과`를 표시한다. 시각은 DB에 보존하고 화면에서는 분 단위로 자동 갱신한다.

예약 회차는 한국 시간 19:50 / 21:50 / 23:50 / 다음 날 01:50이다. 예약 선택 시 가장 가까운 회차를 제안하며 영업일·회차를 직접 변경할 수 있다. 당일 방문은 퇴장 제한 없음으로 선택한다. 고객 주문이 먼저 들어오면 제한 없음으로 시작하고 관리자가 이후 예약 시각을 지정한다.

결제 완료 즉시 합석 그룹 전체가 빈 테이블로 전환된다. 시간 표시는 종료되고 다음 손님은 새 방문으로 시작한다. 예정 시각이 지나도 자동 퇴장이나 주문 차단은 하지 않는다.

## 메뉴와 준비 담당

메뉴 옵션은 고객·POS·API·DB에서 완전히 제거한다. 과거 주문의 옵션 내역도 삭제하지만 주문 수량과 금액 스냅샷은 유지한다.

조리 메뉴는 주방에서 준비하고 조리 완료 후 서빙으로 이동한다. 주류·음료 및 제조 하이볼은 접수 즉시 서빙 탭에서 준비한다. 음식과 음료가 섞인 주문도 항목별로 배분한다. 고객에게 서빙 완료를 표시하는 시점은 실제 POS 서빙 완료 시점이다.

## 엽전 주문

| 메뉴 | 개당 엽전 |
| --- | ---: |
| 소주 | 9개 |
| 맥주 | 9개 |
| 바나나우유 하이볼 | 10개 |
| 믹스커피 하이볼 | 10개 |
| 식혜 | 8개 |
| 얼박사 | 8개 |

일반 메뉴와 이벤트 주문은 같은 메뉴의 원화/엽전 주문 경로다. 장바구니·접수는 분리하고 주문 내역에서 함께 구분하여 표시한다.

고객 주문 → 서빙 탭 접수 → 직원 실물 엽전 수령 확인 → 서빙 완료 순서다. 수령과 서빙 상태를 분리하고 동시/반복 수령 요청은 한 번만 기록한다. 테이블 원화 결제액에 엽전을 포함하지 않고 학생회비·서비스 할인도 적용하지 않는다.

## 판매 통계

메뉴별 판매 수량은 일반·학생회비 납부자·서비스·엽전 수량의 합계다. 판매금액에는 원화 세 분류만 합산한다. 엽전 주문은 펼친 메뉴 아래 별도 행에서 판매 수량·실제 수령 사용량·미수령 엽전을 확인한다. 접힌 메뉴에서도 원화와 엽전을 따로 표시한다.

원화 고객 주문은 접수 시 일반가로 집계하고 할인 결제 완료 후 학생회비 납부자 분류 및 할인 금액으로 변경한다. 서비스는 주문 당시 할인율을 적용한다. 실제 엽전 사용량은 수령 확인 기준이며 원화로 환산하지 않는다. 통계 기간은 주문일을 기준으로 한다.

## 이벤트 메뉴 관리와 영구 삭제

POS 설정의 메뉴 편집에서 `이벤트 주문 허용`과 `엽전 가격`을 저장한다. 가격은 양의 정수이며 이벤트 주문을 해제해도 원화 주문은 유지한다. 가격 변경과 해제는 이후 주문에 적용하고 이미 접수한 주문의 엽전 수량은 유지한다.

`판매 중` 해제는 품절 처리다. `메뉴 영구 삭제`는 확인 후 메뉴 카탈로그 행을 실제 삭제한다. 과거 및 진행 중 주문의 이름·수량·금액과 엽전 수령·서빙·결제·통계는 보존한다. 삭제된 ID의 재사용을 막아 기존 주문과 새 메뉴가 혼동되지 않도록 한다.

## 개별 조리와 서빙 묶음

주방 신규 주문의 체크박스는 선택한 1개만 조리 시작한다. 조리 중의 체크박스는 선택한 1개만 조리 완료한다. 동일 메뉴 여러 개도 독립적으로 처리한다. 전체 조리 시작은 신규 카드의 항목만, 전체 완료는 조리 중 카드의 항목만 처리한다.

완료 처리 한 번당 서빙 카드 하나를 생성한다. 개별 완료는 각각 별도 카드이며 한 번의 전체 완료로 처리한 항목은 한 카드에 묶는다. 같은 주문에서 나중에 완료된 항목을 이전 카드에 합치지 않는다. 서빙 완료는 누른 카드의 항목만 처리한다.

주류·음료는 별도 영역이나 준비 단계 없이 주문 즉시 기존 서빙 대기에 표시한다. 엽전 주문의 실물 수령 확인 정책은 유지한다. 주문 금액과 판매 통계는 원래 주문 항목을 기준으로 유지하고 조리·서빙을 위한 개별 기록만 별도로 관리한다.
