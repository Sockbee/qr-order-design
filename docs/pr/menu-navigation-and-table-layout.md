# 메뉴 탐색 위치 유지 및 한신포차 테이블 배치 개선

메뉴 상세에서 목록으로 돌아올 때 첫 카테고리로 초기화되던 문제를 수정한다. POS에는 2026-09-16 좌석도의 T01~T23 배치를 적용하고, POS 방향과 창문 쪽 방향을 선택할 수 있도록 한다.

- 브랜치: `fix/menu-navigation-and-table-layout`

## 고객 메뉴 탐색

음료 목록을 내려 보다가 메뉴 상세를 열고 돌아오면 선택했던 음료 카테고리와 목록 스크롤 위치를 복원한다. 화면의 뒤로 가기, 브라우저 뒤로 가기, 장바구니에 담은 뒤 목록 복귀에 적용한다.

- 카테고리와 목록 위치를 화면 전환 후에도 유지되는 앱 상태에 보관한다.
- 메뉴 상세는 맨 위에서 열리며, 다른 카테고리를 선택하면 해당 목록의 맨 위로 이동한다.
- 저장된 카테고리가 더 이상 없으면 첫 카테고리를 표시한다.
- 메뉴 탐색 상태는 현재 앱 실행 중 유지한다. 페이지 전체 새로고침 후 복원은 포함하지 않는다.

## POS 테이블 배치 및 방향 선택

그림은 창문 쪽 시점이다. 최초 기본 화면은 이를 180도 회전한 `POS → 입구` 방향이다.

- 창문 쪽 기준 왼쪽은 이벤트 표시, T01, T02 순서다.
- 중앙의 세 열은 각각 T03~T06, T07~T10, T11~T14이며, 각 열의 위·아래는 사각형, 가운데 둘은 원형이다.
- 다음 열은 마름모 T15~T17과 원형 T18이다.
- 맨 오른쪽은 T19~T21, T22~T23이다. 붙어 있는 자리도 4인 단위로 독립 선택한다.
- 이벤트는 번호가 없는 공간 표시이며 주문·입장·합석 대상이 아니다.
- 배치도 상단 `보기 방향`에서 `POS → 입구`와 `창문 쪽에서 보기`를 선택한다. 위치만 회전하고 번호, 상태, 글자 방향은 유지한다.
- 방향은 기기 브라우저에 저장하며, 테이블 홈·상세 배경·이동·합석 배치도에 공유한다. 방향 변경 시 선택된 테이블도 유지한다.
- 기존 T24 이후 운영 테이블은 등록되어 있으면 `배치도 외 테이블`에 계속 표시한다. 운영 DB, 기존 테이블 ID, QR 연결, 주문·결제 기록은 수정하지 않는다.
