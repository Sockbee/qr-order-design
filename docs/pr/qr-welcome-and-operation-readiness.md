# QR 입장 화면 개선 및 운영 예약·테이블 배치·배포 안정화

QR 입장 화면에 검은 배경과 불씨 애니메이션을 적용하고, 행사 운영에 필요한 시작 시각 변경과 최신 테이블 배치를 반영합니다. DB 연결 풀이 혼잡할 때 정상 직원 토큰이 만료된 것으로 처리되던 문제와 CI 부하 테스트의 조회 누적 문제도 함께 수정합니다.

- 대상: `feat/qr-welcome-embers` → `dev`
- 범위: 최신 `origin/dev` 대비 변경. 운영 시작 초기화·통계 분리의 기본 구현과 음료 이미지 변경은 이미 기준 브랜치에 포함되어 있습니다.

## 주요 변경

### QR 입장 화면

- [Figma S01](https://www.figma.com/design/u5pXNGrYEdVDbvqmJLglUS/ui-ux?node-id=14-2)의 로고·을지로 서체·여백과 공용 56px 버튼을 재사용합니다. 로고 아래에 `소프트 일일호프`를 한 번 표시하고, 테이블 번호·결제 안내·메뉴 보기 순서로 구성합니다.
- [참고 영상](https://www.youtube.com/shorts/5II6_NEx4A0)처럼 어두운 배경 위로 작은 불씨가 올라오고, 하단에 은은한 붉은 열기가 보이도록 구현합니다. 배경 색상은 입장 화면에만 적용합니다.
- `WelcomeEmbers`에서 Canvas로 입자의 속도·회전·밝기를 다르게 그립니다. 외부 영상 재생 없이 반복되며, 글자 주변 입자의 밝기를 낮춰 가독성을 확보합니다.
- 입자 수·해상도·그리기 주기를 제한하고, 숨겨진 탭에서는 그리기를 중지합니다. 화면 이탈 시 프레임·크기 감지·이벤트 리스너를 정리합니다.
- `움직임 끄기/켜기`와 시스템의 동작 줄이기 설정을 지원합니다. 로딩 중 메뉴 버튼 비활성화, 잘못된 QR 안내, 재시도 동작을 유지합니다.

### 운영 시작 예약 변경

- 운영 전환 시각을 2026-09-17 **18:00 → 17:00(Asia/Seoul)**으로 변경한 운영 기록과 안내를 반영합니다.
- 예약 스크립트에 `--reschedule-from`을 추가합니다. 명시한 기존 시각이 DB와 일치하고, 기존·새 시각이 모두 미래이며, 전환이 완료되지 않은 경우에만 예약을 바꿉니다.
- 변경은 기존 DB 잠금 안에서 실행하고, 이전·새 시각을 `OPERATION_CUTOVER_RESCHEDULED` 감사 로그에 남깁니다. 일반 예약 명령으로 기존 시각을 덮어쓰는 동작은 허용하지 않습니다.

### 테이블 배치

- 9월 17일 도면에 맞춰 T01~T18과 입구·이벤트 공간 위치를 갱신하고, T11·T15를 마름모 테이블로 표시합니다.
- 공유 배치 데이터를 사용하는 테이블 홈·합석·이동 선택 화면에 함께 적용합니다. 기본 POS 방향과 창문 기준 방향의 180도 회전 관계를 유지합니다.
- 테이블 ID·QR·주문 기록과 각 테이블의 4인 정원은 유지합니다. 행별 순서·모양·회전 배치를 확인하는 테스트를 갱신합니다.

### 직원 인증과 CI 안정화

- 정상 직원 토큰 검증 중 DB 연결 자원이 부족하면, 기존 `401` 대신 **`503 SERVER_BUSY`**, `retryable=true`, `Retry-After: 1`을 응답합니다. 잘못된 토큰은 계속 `401`로 거절하며, DB 연결이 복구되면 기존 정상 토큰을 사용할 수 있습니다.
- 부하 테스트에서 직원 화면별 조회를 한 번에 하나만 실행하고, 진행 중 도착한 갱신 이벤트는 다음 조회로 합칩니다. 느린 DB에서 비동기 조회가 무제한 누적되던 문제를 해결합니다.
- Cloud Build 작업자를 `E2_HIGHCPU_8`로 변경하고, 백엔드 테스트 실패 시 XML 결과를 로그에 출력합니다. 기존 100개 SSE 연결·420건 주문/알림 검증과 DB 연결 대기 제한은 유지합니다.

## 검증

이번 작업에서 확인한 항목:

- 프런트엔드 테스트 34개 및 `npm run lint` 통과.
- `VITE_API_BASE_URL=/api npm run build` 통과. `/api`는 빌드 검증용 설정이며, 운영 API 연동 검증 결과를 의미하지 않습니다.
- 로컬 QR 테스트 화면에서 메뉴 이동, 잘못된 QR 진입 차단, 애니메이션 재생·정지·재개, 동작 줄이기 설정을 확인했습니다.
- 모바일 320/375/390/430px에서 화면 구성과 메뉴 버튼 배치를 확인했습니다. 최종 불씨 버전은 앱 내 브라우저에서 재생·정지·새로고침 후 표시를 확인했습니다.
- `git diff --check` 통과.

운영·배포 변경의 기존 검증 기록은 [17시 예약·테이블 배치·배포 기록](operating-day-1700-layout-deploy.md)에 있습니다. 해당 기록에는 백엔드 전체 테스트 44개, 별도 PostgreSQL에서의 예약 변경·거절 조건, DB 연결 부족 시 직원 API의 503/401 구분 및 연결 복구, Cloud Build 성공 결과가 포함돼 있습니다. 이번 첫 화면 작업에서 백엔드 검증을 다시 실행하지는 않았습니다.

## 배포 및 확인 사항

- 기존 운영 기록상 17시 예약 변경·테이블 배치·백엔드 수정은 Cloud Build `390951b6-e13f-4d02-920f-88283856353f`로 배포됐습니다. **이번 QR 첫 화면 변경은 로컬 구현·검증 상태이며 아직 운영에 배포하지 않았습니다.**
- 코드 병합만으로 DB 예약 시각을 변경하거나 초기화를 다시 실행하지 않습니다. 이미 실행한 예약 변경 명령과 적용 당시 상태는 위 운영 기록을 참고합니다.
- `E2_HIGHCPU_8` 설정은 Cloud Build 작업자 사양을 변경하므로 빌드 비용에 영향을 줄 수 있습니다.
- 배포 후 실제 테이블 QR의 번호·메뉴 진입과 직원 화면의 최신 배치를 확인합니다. 이미 열어 둔 POS는 새로고침해 새 버전을 받습니다.
